### 3.2 `cycle.py` — معالجة `-2` + اسم ملف فريد

```python
sid = journal.log_signal(card, res["verdict"].votes, mode="paper")
if sid == -1:
    print("bot: daily cap reached")
elif sid == -2:
    print("bot: duplicate signal, skipped")
else:
    chart = None
    try:
        from telegram_bot.charts import render_signal_chart, DIR
        chart = render_signal_chart(
            df, card, path=DIR / f"signal_{card.symbol}_{sid}.png")
    except Exception as e:
        print(f"bot: chart failed: {type(e).__name__}")
    print(f"bot: queued signal #{sid} -> "
          f"{review.queue(api, cfg, sid, card.text(), chart)}")
```
